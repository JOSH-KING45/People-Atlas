People Atlas source export

Current application source, dependencies lockfile, tests, fonts and database migration files.
Install dependencies with pnpm install using Node.js 22.13 or newer.
Run pnpm dev for development and pnpm build for a production build.

This is a source-code export, not a backup of saved people or uploaded documents. Export your records separately from Files & export in the app. API keys, runtime secrets and installed dependencies are excluded.

Cloud authentication and database/file storage depend on the existing Sites environment. Independent hosting requires configuring these services and adapting authentication; this ZIP does not perform that migration.
